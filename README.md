# 📘 Caderno Temático: Python do Zero ao Avançado com NotebookLM

## 🎯 Contexto e Objetivos

Este repositório documenta meu processo de aprendizagem utilizando o **Google NotebookLM** como ferramenta de apoio aos estudos de **Python**, desde os conceitos básicos até tópicos mais avançados.

O principal objetivo foi utilizar a Inteligência Artificial de forma estratégica para organizar conteúdos, aprofundar conceitos, esclarecer dúvidas e criar um material de consulta que possa ser reutilizado durante minha jornada como desenvolvedor.

### Objetivos específicos

- Aprender Python do nível básico ao avançado;
- Consolidar conceitos por meio de resumos estruturados;
- Desenvolver habilidades de engenharia de prompts;
- Criar um material de revisão organizado e reutilizável;
- Utilizar IA como ferramenta de apoio ao aprendizado ativo.

# ⚠️ Cicatrizes (Troubleshooting)

Durante o processo de aprendizagem foi possível perceber que a qualidade da resposta depende diretamente da qualidade do prompt utilizado.

## Exemplo 1

### Prompt inicial

> Explique Python.

**Problema**

A resposta ficou muito ampla e superficial.

### Prompt melhorado

> Explique apenas os tipos de dados primitivos do Python, mostrando exemplos práticos e situações de uso.

**Resultado**

A resposta tornou-se muito mais objetiva e útil.

---

## Exemplo 2

### Prompt inicial

> Fale sobre listas.

**Problema**

Resposta genérica.

### Prompt melhorado

> Explique listas em Python mostrando criação, indexação, slicing, principais métodos e complexidade das operações.

**Resultado**

A resposta apresentou informações muito mais completas e organizadas.

# 📖 Glossário

| Conceito | Definição |
|----------|-----------|
| Variável | Espaço utilizado para armazenar valores na memória. |
| Lista | Coleção ordenada e mutável. |
| Tupla | Coleção ordenada e imutável. |
| Dicionário | Estrutura composta por pares chave e valor. |
| Conjunto (Set) | Coleção não ordenada que não permite elementos duplicados. |
| Função | Bloco reutilizável de código que executa uma tarefa específica. |
| Classe | Estrutura utilizada para criar objetos. |
| Objeto | Instância de uma classe. |
| Exceção | Erro que pode ser tratado durante a execução do programa. |
| Módulo | Arquivo Python contendo funções, classes e variáveis reutilizáveis. |
| Pacote | Conjunto de módulos organizados em diretórios. |
| Decorator | Função que modifica o comportamento de outra função. |
| Gerador | Função que produz valores sob demanda utilizando `yield`. |
